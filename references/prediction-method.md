# 预测与策略方法

## 当前评估结论

已审计的 Phase 8A 收尾保留 `distance_only`，完整模型已被验证拒绝。本协议/队列未进入留出集评估；`model_validated=false` 且 `user_facing_prediction_allowed=false`。

- 模型输出只能称为“研究基线”“研究候选”“情景估计”或“历史回放”。
- 不得称其为已验证预测或承诺准确性。
- 不得利用验证/留出集结果调参，也不得重新进入已关闭协议。
- 多路径/参考模型保持内部状态，除非另有冻结评估证明可提升。

## 计算纪律

目标赛道必须绑定官方距离、爬升与路线版本；优先使用跑者自身合格历史。`distance_only` 变换及每一项调整必须可检查。历史稀少、距离外推、爬升不确定、低等级赛道资料、状态/天气不确定或路径冲突时，扩大区间。

仅在上游契约许可时展示保守、稳定、进取情景。黄色状态禁用进取方案；红色状态停止全部成绩目标。没有已核验 CP 结构的 C 级赛道不得伪造 CP 时刻表。

将 CP 到达、站停、关门余量、营养、装备、天气调整分别处理；除非进出站计时证明实际离站，否则计划离站时间始终标为计划。
