# 来源策略

先用第一方官方网页/文件，其次是用户提供的第一方证据、带指纹的本地回放，最后才是明确标注的第三方材料。第三方主张不得合并为官方事实。

允许：访问普通公开网页；解析用户提供或既有抓取的 HTML、JSON、文本、图像和文档；仅在来源指纹、schema、查询身份与解析器版本一致时复用缓存。

禁止：猜测或调用未公开/内部 API；绕过登录、订阅、CAPTCHA、机器人检查、限流或反爬；仅因页面公开即批量采集；修改原始证据使后续抓取看似原始。

遇到 `401`、`403`、`429`、人工验证或解析器故障，停止使用受影响来源，记录精确错误，继续正常公开兜底搜索；只有公开解析后跑者身份或目标组别仍有歧义时才询问请求者。

ITRA 必须先按姓名搜索，再以精确 Runner ID 接受个人档案；锁定结果与 `DNF` 都是明确状态，不得推断为完赛。

赛事证据绑定名称、年份、组别、路线版本；天气与计时保留发布时间/赛事时间及抓取/接收时间。原始抓取保存在新的时间戳证据目录。

必需赛事搜索通道：当年官方赛事/规程、官方报名/组别页、路线/路书/GPX/附件、CP/补给/关门材料、官方通知/社媒、计时/追踪、可核验历史路线/成绩。每个发现附件必须为已获取并解析，或记录 `attachment_not_acquired` / `attachment_parse_failed` 与自动兜底动作。
